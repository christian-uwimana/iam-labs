# IAM labs

Hands-on identity and access labs, built in my own Microsoft Entra ID test tenant with Active Directory and Azure. Each lab sits in its own folder with a README, the scripts it uses and screenshot evidence of every step.

| Lab | What it shows |
| --- | --- |
| [Netskope provisioning with the on-prem UPN](entra-scim-provisioning-on-prem-upn/) | An app that needs the on-prem UPN over SCIM: the unsupported schema edit and why it quarantines, the supported fix with a Connect Sync rule, and alerts. |

For a larger set of related projects, see [iam-banking-lab](https://github.com/christian-uwimana/iam-banking-lab).
